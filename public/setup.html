Connection tips & motion controls +

Connected, but no input?

Allow Accessibility for the app running the server (Terminal or Codex) in System Settings → Privacy & Security → Accessibility. Recheck here, then click the Ryujinx game window. Input pauses when you switch away.

Using motion controls?

Buttons work over Wi-Fi in the browser. Phone sensors require HTTPS or the native Expo app. Stock Ryujinx ignores gyro from keyboard controllers; it needs the project’s motion patch.

Playing together?

Each phone chooses a different player. Some games require separate physical controllers and will reject two keyboard-backed players. Choose a layout that your game supports.
